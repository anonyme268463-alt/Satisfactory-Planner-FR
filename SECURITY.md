# Security Policy

## Versions supportées
Le projet est actuellement maintenu pour :
| Version | Support |
| ------- | ------- |
| 1.0+    | ✅ |
| <1.0    | ❌ |

## Signalement d’une vulnérabilité
Si vous découvrez un problème de sécurité, merci de :
- Ouvrir une issue privée si possible
- Décrire clairement :
  - La faille
  - L’impact potentiel
  - Les étapes de reproduction
  - Une suggestion de correction si disponible

## Champs concernés
Les signalements utiles incluent :
- Injection JavaScript
- Mauvaise validation de données
- Fichiers corrompus
- Dépendances vulnérables
- Exposition accidentelle de données

## Bonnes pratiques du projet
- Aucune donnée sensible utilisateur stockée
- Aucun backend critique
- Hébergement statique GitHub Pages
- Validation des entrées recommandée
- Vérification régulière des dépendances

## Objectif
Garantir un outil fiable, transparent et sécurisé pour tous les utilisateurs.
